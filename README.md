# qSa3ed Studio

**Building software, tools, and digital experiences.**

qSa3ed Studio is an independent software studio focused on creating useful, creative, and well-crafted digital products.

We explore different areas of technology — from developer tools and desktop applications to web platforms, games, automation, infrastructure, and more.

## What We Do

We build software across different areas, including:

* **Software & Applications**
* **Developer Tools**
* **Web Applications**
* **Desktop Applications**
* **Games & Game Tools**
* **Automation**
* **Infrastructure & Server Systems**
* **Utilities**
